# Evocação de eco

- **Categoria:** Efeitos
- **Salvar em:** `client/public/assets/efeitos/evocacao.png`
- **Formato:** Folha 2×2 com quatro quadros de animação, fundo transparente
- **Tamanho a pedir:** 1024x1024

## Prompt (copie e cole no ChatGPT)

```text
2D pixel art game asset in 16-bit JRPG style. Crisp hard-edged pixels, visible pixel grid, no anti-aliasing, no blur, no smooth gradients, no photorealism, no 3D render. Limited palette of about 24 colors: near-black, charcoal, deep violet and indigo as base, with small cyan, violet or amber glowing accents. Dark modern-fantasy mood. 1-pixel dark outline around every shape. Light source from the top-left. No text, no letters, no numbers, no watermark, no signature, no UI frame.

Subject: a dark violet shadow rising from the ground as a pillar of smoke with cyan sparks, four animation frames in reading order: ground circle, rising, peak, dissipating.

Output: one sheet, square 1024x1024 canvas, divided into an exact 2 columns x 2 rows grid of equal 512x512 cells, no grid lines. Four animation frames of the same effect in reading order (top-left, top-right, bottom-left, bottom-right), each centered in its cell. Fully transparent background (PNG with alpha). No ground shadow, no floor, no backdrop.
```

## Antes de salvar, confira

- [ ] Quatro quadros na ordem de leitura.
- [ ] Cada quadro centralizado na sua célula.
- [ ] O fundo é transparente.
- [ ] O estilo bate com os assets já aprovados (mesma paleta e mesmo contorno).
