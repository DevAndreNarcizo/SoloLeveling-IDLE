# Objetos do Bosque Cinzento

- **Categoria:** Mapas: objetos de cenário
- **Salvar em:** `client/public/assets/mapas/bosque-cinzento-objetos.png`
- **Formato:** Folha 2×2 com quatro objetos de cenário, fundo transparente
- **Tamanho a pedir:** 1024x1024

## Prompt (copie e cole no ChatGPT)

```text
Dark fantasy RPG game art, anime style illustration, highly detailed, sharp focus, dramatic rim light. Rich but dark palette: charcoal, deep violet and indigo, with cyan, violet or amber glowing accents. No text, no letters, no numbers, no watermark, no signature, no UI frame.

Subject: four separate props, one per cell: a dead grey tree, a mossy boulder, a thorn bush, a fallen log.

Output: one sheet, square 1024x1024 canvas, divided into an exact 2 columns x 2 rows grid of equal 512x512 cells, no grid lines. Exactly one prop per cell, centered, top-down 3/4 view, with at least 32 pixels of empty margin on every side of its cell. Fully transparent background (PNG with alpha). No ground shadow, no floor, no backdrop.
```

## Antes de salvar, confira

- [ ] Exatamente quatro objetos, um por célula, sem invadir a célula vizinha.
- [ ] O fundo é transparente.
- [ ] O estilo bate com os assets já aprovados (mesma paleta e mesmo contorno).
